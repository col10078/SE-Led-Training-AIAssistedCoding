# Vocab Level Set

| Term                      | Definition                                                                                                                           |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **VS Code**               | The free editor where we'll write code and talk to Copilot. Our home base.                                                           |
| **Git**                   | The version-control tool that tracks changes and talks to GitHub. Runs on your machine.                                              |
| **GitHub**                | Cloud home for code. Stores projects and codebases and is where you've created an account and accessed the pre-work.                 |
| **GitHub Copilot**        | The AI assistant inside VS Code. "Chat" answers questions; "Agent mode" acts on your files.                                          |
| **Node.js**               | Runs JavaScript outside the browser. Powers Experience Builder and our web tooling.                                                  |
| **npm / npx**             | Node's package tools. `npx` runs a tool once - it's how we run tools and commands.                                                   |
| **localhost**             | Your own machine acting as a web server. `localhost:3000` = a site running only on your PC.                                          |
| **Languages**             | Python (Notebooks / ArcPy), JavaScript / TypeScript (SDK, ExB), HTML / CSS (Hub cards).                                              |
| **Markdown (.md)**        | A lightweight plain-text formatting syntax that uses simple symbols to style text, which then renders as formatted output.           |
| **Terminal / PowerShell** | A text-based interface where you type commands to control your computer directly, instead of clicking through a graphical interface. |
